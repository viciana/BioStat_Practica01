# Instrucciones de proyecto

Repositorio de la práctica 1 de Bioestadística (2º de Medicina):
presentación org-mode → beamer → PDF con jamovi, datos simulados en R y
capturas anotadas. Proyecto en **mantenimiento**, no en desarrollo activo.

**Antes de nada, lee `ESTADO_PROYECTO.md`**: ahí está el estado del
proyecto, la estructura detallada, las convenciones de las diapositivas,
el procedimiento de capturas de jamovi y las decisiones de alcance ya
tomadas por el usuario. `README.md` es la cara pública (compilar,
licencia); `ESTADO_PROYECTO.md` es la memoria de trabajo.

Para retocar algo: trabajar en una rama, `make` para regenerar, revisar
el PDF, y `git commit` + `git push` solo cuando el usuario lo apruebe. Si
cambian `datos/*.R` o los `.omv`/`.csv` que generan, hay que volver a
subirlos a `https://epidemos.es/bs2026/` (ver `ESTADO_PROYECTO.md`).

La carpeta `S1` (fuera de este repositorio) es el taller histórico donde
se gestó el proyecto; no se mantiene ni se sincroniza con este repo.
